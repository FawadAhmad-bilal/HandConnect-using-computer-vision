# 🖐️ HandConnect - AR Hand Tracker

Real-time Augmented Reality hand tracking with rainbow glowing effects using MediaPipe and OpenCV.

## ✨ Features
- 🌈 Rainbow glowing lines on hand landmarks
- 👋 Gesture detection (Pinch / Open Hand / Closed)
- 🤝 Inter-hand connections when both hands detected
- 📊 Real-time FPS counter
- 💡 Spread percentage calculation

## 🛠️ Tech Stack
- Python 3.14
- MediaPipe 0.10.35
- OpenCV 4.13
- NumPy

## 🚀 Installation

```bash
pip install mediapipe opencv-python numpy
```

## ▶️ Run

```bash
python main.py
```
